# Задание 2. API-пайплайн: данные → LLM → результат

## Описание задачи

Скрипт `main.py` читает файл `travel_requests.csv` с запросами на подбор путешествия, отправляет каждый запрос в LLM Xiaomi MiMo через API (совместимый с OpenAI) и сохраняет структурированный ответ в `output.json`.

Тема: **Travel-планировщик** – по одной фразе пользователя модель определяет:
- направление (destination)
- бюджет (budget_estimate)
- чем заняться (activities)
- тип жилья (accommodation)
- лучшее время для поездки (best_time)

## Инструкция запуска

1. Скачайте скрипт и csv-файл в одну папку.

2. Установите библиотеку openai

3. **Получите API-ключ** от сервиса Xiaomi MiMo.  
   - Зарегистрируйтесь на [Xiaomi MiMo Open Platform](https://platform.xiaomimimo.com), создайте ключ.  
   - Или можете использовать мой ключ.

4. Откройте файл `main.py` и **замените значение переменной `API_KEY`** в самом начале на свой ключ:
   ```python
   API_KEY = "ваш_ключ_сюда"

5. Убедитесь, что файл travel_requests.csv находится в той же папке.

6. Запустите скрипт командой: python main.py

7. Результат сохранится в output.json.
